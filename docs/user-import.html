A–W Import Data

จัดเตรียมข้อมูลผู้ใช้ 23 คอลัมน์

อิงโครงสร้างไฟล์ Excel ที่คุณส่งมา: ID, Code, Campus, Email, ชื่อ–นามสกุล, ประเภทผู้ใช้, สัญชาติ และสถานะ

ข้อมูลส่วนบุคคล: เครื่องมือนี้ทำงานในเบราว์เซอร์ของคุณ และไม่ส่งไฟล์ขึ้นเซิร์ฟเวอร์ กรุณาใช้บนเครื่องที่เชื่อถือได้และเก็บไฟล์ที่ได้ในที่ปลอดภัย

สร้างไฟล์ตัวอย่างสำหรับนำเข้า

แนะนำให้ใช้ Excel (.xlsx) ซึ่งช่วยรักษาเลขศูนย์นำหน้าในรหัสวิทยาเขต รหัสประจำตัว และเลขบัตรประชาชน

↓ ดาวน์โหลดแม่แบบ Excel A–W

ค่าเริ่มต้นจากหมายเหตุ: A และ B ใช้รหัสเดียวกัน, C = 001, N เว้นว่างถ้าไม่ใช่ผู้ปกครอง, P = 0 หากไม่มี, T = THAI หรือ OTHER, W = Active

ตรวจสอบความถูกต้องไฟล์ Excel / CSV

รองรับ Excel .xlsx หรือ CSV UTF-8 ที่มีคอลัมน์ A–W และตรวจสอบรูปแบบหลักก่อนนำเข้าระบบปลายทาง (ไม่ใช่เครื่องมืออัปโหลดรายชื่อ)
